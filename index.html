Hands-on Lab Runbook

Package CraveCraft with Docker, Git & Kubernetes

Save this page as index.html inside a new project folder, then run these steps in your Linux terminal to practice **Docker + Git + Kubernetes** together:

1. Create Dockerfile 
FROM nginx:alpine
# Remove default nginx static assets
RUN rm -rf /usr/share/nginx/html/*
# Copy CraveCraft single-file app into nginx web root
COPY index.html /usr/share/nginx/html/index.html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
2. Build Image & Push to Docker Hub 
# Build v1.0.0 image (replace YOUR_DOCKERHUB_USER)
docker build -t YOUR_DOCKERHUB_USER/cravecraft:v1.0.0 .

# Test locally on port 8080
docker run -d -p 8080:80 --name cravecraft-test YOUR_DOCKERHUB_USER/cravecraft:v1.0.0

# Push to Docker Hub so Kubernetes can pull it
docker login
docker push YOUR_DOCKERHUB_USER/cravecraft:v1.0.0
3. Deploy to Kubernetes (k8s-manifest.yaml) 
apiVersion: apps/v1
kind: Deployment
metadata:
  name: cravecraft-deploy
spec:
  replicas: 3
  selector:
    matchLabels:
      app: cravecraft
  template:
    metadata:
      labels:
        app: cravecraft
    spec:
      containers:
      - name: cravecraft-web
        image: YOUR_DOCKERHUB_USER/cravecraft:v1.0.0
        ports:
        - containerPort: 80
---
apiVersion: v1
kind: Service
metadata:
  name: cravecraft-svc
spec:
  type: NodePort
  selector:
    app: cravecraft
  ports:
  - port: 80
    targetPort: 80
    nodePort: 30080
Tip: Change v1.0.0 to v2.0.0 to practice kubectl set image rolling updates!
